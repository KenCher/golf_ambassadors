VS2513 VS2513 zKVM: PCI Migration - vfio-pci (PCI passthrough) COMPLETED LAST WEEK• I started experimenting with vfio pci live migration with MLX devices. I found some issues that would need further discussion on things we need to consider for both RoCE and NETD devices. RoCE which technically are VFs are considered as isolated VFs. This makes the struct pci_dev is_virtfn to be set to 0. And so it fails in mlx5vf_cmd_set_migratable() NETD VFs which are VFs with the PF on the same LPAR, it fails due to MLX5_CAP_GEN(mvdev->mdev, migration) in mlx5vf_cmd_set_migratable(). This indicates the NETD firmware doesn't support migration. The current firmware version on the cards is 26.42.1000. NVIDIA docs recommend version 28.41.1000 or 32.41.1000 (https://networking-docs.nvidia.com/doca/archive/3-4-0/sr-iov-live-migration).CURRENTLY WORKING ON• Investigate and understand live migration with MLX devices.BLOCKERS• None COMPLETED LAST WEEK• I was trying to see if we could update the firmware on RoCE and NETD devices. But while discussing this with firmware team, I also learned that NETD and RoCE devices are an older generation of Mellanox devices (ConnectX-6) and so it can't support live migration. Live migration is only supported on ConnectX-7, which are the Musica adapters.CURRENTLY WORKING ON• I am trying to see if we can get Musica adapters on B34 for KVM LPARs.BLOCKERS• None Critical ⚠️️ 2026-08-10
